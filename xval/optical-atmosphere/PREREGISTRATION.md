# Pre-registration: optical atmosphere model (0.37)

Committed alone, before any module is implemented and before any scored run. Bars may be
tightened after a run, never loosened. A miss is recorded NOT MET with its numbers and pinned by a
test that asserts the miss. Design context: `docs/design/optical-atmosphere-0.37.md`.

## What is and is not claimed

No external measured-availability or ITU worked-example oracle is selected at this commit. The
ITU-R validation numbers are an open owner licence call and stay out of the repo. Therefore:

- Section A bars are **cross-implementation and closed-form identity** checks. They may add
  VALIDATED rows only as identities, the repo's existing convention for closed forms; they do not
  validate the physical atmosphere.
- Section B (external oracle) is **reserved**. It can be filled only by an addendum that is
  committed, with the oracle's citation, licence and numbers' provenance, before the run it
  governs. Until then every weather-, turbulence-, cloud- or technique-dependent output is
  MODELLED.

## A. Bars fixed now

Oracle for A1-A3: an independent program (`xval/optical-atmosphere/oracle.py`, numpy/scipy at the
versions in `xval/oracles/requirements.frozen.txt`) that evaluates the same published formulas by
adaptive numerical quadrature, sharing no code with kshana. Fixtures are generated by that script
and written under `tests/fixtures/optical_atmosphere/`.

- **A1 Rytov variance.** Plane-wave and spherical-wave Rytov variance along slant paths for
  Hufnagel-Valley 5/7 (and the ground-level/wind parameter sweep of the grid below), at 850, 1064
  and 1550 nm, zenith angles {0, 30, 60, 75} deg, uplink and downlink. Bar: relative error
  <= 1e-6 against the oracle at every grid point.
- **A2 Scintillation / fade.** Weak-turbulence scintillation index, aperture-averaging factor and
  gamma-gamma fade probability at fade depths {1, 3, 6, 10} dB on the A1 grid. Bar: relative error
  <= 1e-6 (probabilities compared in log10, absolute <= 1e-6).
- **A3 Extinction and cloud.** Beer-Lambert slant transmission (clear-air plus cloud, cloud
  optical depth from liquid-water column L and effective radius r_e as tau = 3 L / (2 rho_w r_e))
  on L in {0.01, 0.1, 0.5, 2} kg/m^2, r_e in {6, 10, 15} um. Bar: relative error <= 1e-12.
- **A4 Diversity limits.** rho = 0 equals the independent union `1 - prod(1 - a_i)` to <= 1e-12;
  rho = 1 equals the single-site availability to <= 1e-12; availability is non-decreasing in N and
  non-increasing in rho for every grid point (zero violations).
- **A5 No moved output.** With no atmosphere block, `optical_link_budget` output is bit-identical
  to the base commit 5eac3b61 over a grid of 1,000 parameter sets (`f64::to_bits`), and
  `optical_availability::default_network` outputs are unchanged.
- **A6 Holdover coupling.** Per-outage timing error equals `holdover::coast_phase_sigma` at the
  outage duration bit for bit; range error equals `phase_to_range_m` of it.
- **A7 Portability.** Native and wasm builds produce byte-identical report output for the bundled
  scenarios (the STUDIO-15 portable-maths rule).

## B. External oracle (reserved, empty)

Eligible: a published measured optical-ground-station or optical-link availability or
cloud-free-line-of-sight record (cited, site and period stated), a published slant-path
scintillation measurement, or ITU-R validation values if the owner permits their use. An
addendum must state the bars before any comparison. Absent one, no physical-fidelity VALIDATED row
is added and the docs page says so.

## Ledger consequence (decided now)

A1-A7 hold: identity/cross-implementation rows may be added (labelled as such). Any miss: NOT MET,
asserted by a test. Everything else: MODELLED.
