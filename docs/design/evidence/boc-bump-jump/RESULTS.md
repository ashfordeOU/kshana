# BOC(1,1) ambiguity resolution (bump-jump) and BOC(1,1) DLL scaling: results

Pre-registration: `PREREGISTRATION.md` (committed at `6b68f6cc`, before these runs). The bars
were not changed after the runs. Reproduce with

```
cargo test --release --test iq_boc_bump_jump -- --nocapture
cargo test --lib iq::track::boc
```

Signal: BeiDou B1C data, PRN 19, seeded 10 ms symbols, 5 MS/s complex, Doppler +1250 Hz,
generated by `iq::scene` with thermal noise. Loop: 10 ms updates, EMLP `d = 0.2` first-order
1 Hz carrier-aided DLL, second-order 10 Hz Costas PLL with a first-order 5 Hz FLL during
pull-in, started 2 Hz off in Doppler. Code error is the replica minus the injected truth.
Label: **MODELLED** (internal consistency against injected truth and closed forms; no external
receiver output is compared).

### Finding F1: the B4 unit-test grid exceeds the discriminators' linear range

The pre-registered unit test asks all three scaled discriminators to be within 10 % of `ε` on
the ideal `1 − 3|τ|` peak for `d ∈ {0.1, 0.2, 0.5}` and `ε ∈ {−0.05, 0.02, 0.08}` with
`|ε| + d/2 < 1/3`. Relative errors of the scaled readings (closed form, identical to the test):

| d | ε | EMLP | dot product | envelope |
|---|---|---|---|---|
| 0.1 | −0.05 | −3.0 % | **+17.6 %** | 0.0 % |
| 0.1 | +0.02 | −0.5 % | +6.4 % | 0.0 % |
| 0.1 | +0.08 | **−32.7 %** | **−17.8 %** | **−30.1 %** |
| 0.2 | −0.05 | −4.4 % | **+17.6 %** | 0.0 % |
| 0.2 | +0.02 | −0.7 % | +6.4 % | 0.0 % |
| 0.2 | +0.08 | **−10.5 %** | **+31.6 %** | 0.0 % |
| 0.5 | −0.05 | **−26.5 %** | **+17.6 %** | 0.0 % |
| 0.5 | +0.02 | −5.5 % | +6.4 % | 0.0 % |
| 0.5 | +0.08 | **−48.0 %** | **+31.6 %** | 0.0 % |

The scaling factors are the exact first-order slopes: a new unit test
(`boc11_scaled_discriminators_have_unit_slope_at_zero_error`) shows every scaled discriminator
within 1 % of unit slope at `ε = ±1e-4`. The misses come from the grid, which was drawn wider
than the discriminators' linear range: with `|ε| ≥ d/2` the early and late taps sit on the same
side of the peak (the EMLP and envelope rows at `d = 0.1, ε = 0.08`); EMLP is a ratio of
squares and bends away from linear as `ε` grows; and the dot product divides by `|P|²` with
`P = 1 − 3|ε|` on the BOC peak, so it reads `ε/(1 − 3|ε|)`-like values. The same
nonlinearities exist for the BPSK normalisations; they are larger here only because the BOC
peak is three times as steep. The bar is not changed: `b4_unit_grid_misses_are_the_recorded_ones` in
`src/iq/track/boc.rs` keeps it as written and asserts the recorded relative errors (to 2e-3)
and the 11 recorded misses, so CI fails if the result moves. The loop behaviour the bar was meant to
protect is covered by B2 and B3, which run inside the linear range.

## B5: correlator level

`BumpJump` alone on seeded `(VE, P, VL)` triples with the BOC(1,1) noise covariance
(`R(0.5) = −0.5`, `R(1) = 0`), `T = 10 ms`, signal on the main peak, 100 000 updates per C/N0:

| C/N0 | False jumps | Bar |
|---|---|---|
| 45 dB-Hz | 0 | 0 |
| 40 dB-Hz | 0 | 0 |
| 35 dB-Hz | 0 | 0 |
| 30 dB-Hz | 0 | 0 |
| 25 dB-Hz | 0 | ≤ 1 |

Detection at 35 dB-Hz, signal on the `+0.5` chip side peak, 1000 trials of 50 updates: 1000
jumped within 50 updates, all towards the main peak (bar: at least 99 %, all towards).

## Run time

The IQ-chain test (B1–B3, three 4 s scenes at 5 MS/s with up to five channels each) and B4/B5
take 32 s together in the release profile on the development container, and 188 s in the
debug test profile (`cargo test`), so they stay in the default test set.

## Not covered

Field IQ (CAP-07 (c)); band-limited front ends (the scene samples the ideal chip waveform);
composite MBOC/QMBOC replicas; any external receiver.
