# DRAFT: `LICENSES/` split proposal

**Status: DRAFT. A licence decision belongs to the owner. No licence file, SPDX header
or README claim changes until the owner says so. `LICENSE` and `LICENSING.md` are
unchanged.**

## Why

Engine code is AGPL-3.0-only (dual-licensed commercially). Text and data meant to be
copied into other people's standards, tools and papers gain from a permissive licence.
The strategy memo recommends this split as a low-cost move.

## Proposal

| Material | Licence | Reason |
|---|---|---|
| Engine, CLI, bindings, Studio code | AGPL-3.0-only (unchanged) | Keeps the dual-licence model. |
| `docs/spec/*`, JSON Schemas, `docs/compliance/*` text | CC-BY-4.0 | Anyone may reuse with attribution; standards bodies can cite. |
| Test vectors, split manifests, fetch-script manifests (SHA-256 lists) | CC0-1.0 | No friction for benchmark use. |
| Third-party data | Never vendored; each source keeps its own licence, recorded in its manifest | JammerTest (GPL-3), TEXBAT, OAKBAT and DataPort are not redistributed. |

## Mechanics (if approved)

- Add `LICENSES/AGPL-3.0-only.txt`, `LICENSES/CC-BY-4.0.txt`, `LICENSES/CC0-1.0.txt`
  (REUSE layout) and a `REUSE.toml` mapping paths to licences.
- Change SPDX headers only on the paths in the table above.
- Files that mix code and spec text (for example docs generated by the binary) stay
  AGPL until split.
- Contributors keep their copyright; the dual-licence contribution terms in
  `CONTRIBUTING.md` apply unchanged to code. Contributors to spec text are asked to
  agree to CC-BY-4.0 in the pull request template (owner to approve the wording).
- `deny.toml` and `scripts/` need no change; add a REUSE lint step to CI.
