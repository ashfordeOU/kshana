Benchmark

Same logs, same rules. Scores in the open.

kshana-bench is a fixed set of tasks, splits and metrics for GNSS interference detection and timing holdover, so that different methods can be compared on the same data. A submission is a file; nothing runs on the submitter's behalf. Baselines are the engine's own monitors, with bars written down before the first scored run.

02What a row means

A score describes a log, not a product.

  • A row says: this file scored X on split S under specification version V. It does not say a product is certified, conformant, approved or endorsed, and no organisation is named as an endorser.
  • The data are recorded or synthetic and named in the specification. Third-party data is never copied into the repository: manifests and fetch scripts pin each file by SHA-256, and each licence is recorded before the data is used.
  • The truth for a recorded log is the test plan's scheduled slots, not recorded on-air times, so a detection probability is a lower bound. The specification says so beside each task.
  • A sealed holdout is scored only in a leaderboard round, and its seed is revealed after it. Bars for any baseline that claims a number are committed before the scored run and never loosened afterwards; a miss is recorded as NOT MET.
  • Advisory only: Kshana results are modelled or measured against stated references, not an approval or a statement of conformance.

Run it yourself: kshana bench score turns a submission and a split's truth into a result file; kshana bench leaderboard renders result files into this page.

Kshana · क्षण · the precise instant

Open-source PNT (positioning, navigation and timing) resilience simulator. It drives no radio hardware and transmits nothing: its signal-level output is baseband IQ sample files, and its software GNSS receiver is an analysis tool. Not a flight product.
