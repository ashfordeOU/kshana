Every command

kshana <scenario.toml> runs a scenario; every other command is a subcommand. kshana --help prints the usage of all of them, and each subcommand's own --help lists its flags. The examples run from a checkout.

Command What it does Example Docs

kshana --study <suite.toml> runs a suite of scenarios into one aggregated, stamped study kshana --study scenarios/quantum-pnt-demonstrator.suite.toml Usage
kshana --validate <scenario.toml> lints a scenario without running it kshana --validate scenarios/gnss-ins.toml Usage
kshana kinds [--json] lists every scenario kind with its required and optional fields kshana kinds Kinds

kshana evidence keygen, verify, attach-timestamp, round-trip signs, verifies and timestamps evidence packs and links a lab run to its score kshana evidence keygen --out signer.key Evidence packs

kshana

Kshana · क्षण · the precise instant

Open-source PNT (positioning, navigation and timing) resilience simulator. It drives no radio hardware and transmits nothing: its signal-level output is baseband IQ sample files, and its software GNSS receiver is an analysis tool. Not a flight product.
