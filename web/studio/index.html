    Views of this result

    Figures of merit

    The tier is each figure's validation status, read from the engine's own figure_tiers block: validated means checked against an independent external oracle; modelled means first-principles physics with tests, not yet oracle-checked.

    Every published figure

    Read from the result document with the unit, note and provenance the engine records for each one.

    Filter health Kalman self-consistency

    A consistent filter's reported uncertainty matches its actual errors. NIS (normalised innovation squared) should sit near 1 and NEES (normalised estimation error squared) near 2, each inside its 95% χ² band.

    Time series

    Each series this run publishes, against time. Hover or drag across the chart to read the values.

    C/N0 by satellite carrier-to-noise density, dB-Hz

    Each cell is one satellite at one epoch from this run. Hatched cells are below the receiver's tracking threshold: that satellite is lost.

    Band

    Interference outcome

    Holdover error since GNSS was lost

    Move the budget and the time-to-breach is read off this run's own error record. The engine's holdover figure, computed at the scenario's budget, is shown alongside and is the authoritative number. Change the clock or the outage in the parameters to re-run the physics.

    MTIE maximum time interval error

    TDEV time deviation

    Mask checks and holdover budgets

    Each check's limit is plotted as a ring at the averaging time where the margin was worst. Masks are transcribed from the ITU-T (International Telecommunication Union Telecommunication Standardization Sector) Recommendations named in each row.

    Clock stability overlapping Allan deviation σy(τ)

    Lower is better. Fractional-frequency stability against averaging time τ, on log axes.
