# kshana-bench: per-dataset licence review

Reviewed 2026-10-18 from each publisher's own page. This is an engineering review, not legal
advice. The rule for every set is the same: **reference, never copy.** No data file of any set
below is in this repository or on the site; a manifest names the file and pins its SHA-256, and a
fetch script downloads it into a git-ignored cache.

## Open items for the owner

1. The licence of the spec text and the manifests is **"CC-BY-4.0 / CC0 proposed, owner decision
   pending"** until the coordinator confirms it.
2. OAKBAT and the DataPort set are out until their terms are read and cited.
3. JammerTest 2024 is GPL-3.0-or-later. Scores and per-case hashes are facts about it and are
   published, the data is not. Counsel should confirm that a leaderboard of scores is not a
   derivative work. This review assumes it is not.
4. TEXBAT: "refrain from distributing" is a request, not a licence term. The bench never
   distributes it.
